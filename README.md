# تعديلات الموقع — الفورم والدفع

الموقع زي ما هو بالظبط. اللي اتضاف بس:

* **سيكشن "ابدأ مشروعك"** في `index.html` و `packages.html` (قبل الـCTA) + زرار **تواصل** في المنيو.
* **الباقات الثلاثة** الثابتة بدل الاتنين القدام (البداية 400 / النمو 600 / الشريك 1500) + **قواعد التعامل** تحتها.
* **زرار دفع بالبطاقة** لكل باقة — بيظهر لوحده أول ما تحط الروابط.
* **بطاقة ائتمانية** اتضافت في طرق الدفع.

كل الإعدادات في أول `assets/app.js`.

---

## 1) تفعيل الفورم — خطوة واحدة

الفورم بيبعت على **karammh112@gmail.com** عن طريق FormSubmit، من غير حساب ولا لوحة تحكم.

1. ارفع الملفات على GitHub Pages.
2. افتح الموقع المرفوع (مش من الجهاز)، املأ الفورم وابعت **أول رسالة**.
3. هيجيلك إيميل من FormSubmit فيه زرار **Activate Form** — اضغطه مرة واحدة.
4. خلاص، كل الطلبات بعد كده توصلك على طول.

**للحماية من السبام (اختياري):** بعد التفعيل FormSubmit بيديك كود مشفّر بدل الإيميل. غيّر السطر ده في `app.js`:

```js
const EMAIL = "karammh112@gmail.com";
```
لـ:
```js
const FORM_AJAX = "https://formsubmit.co/ajax/الكود-المشفّر";
const FORM_POST = "https://formsubmit.co/الكود-المشفّر";
```
كده إيميلك مش هيبقى ظاهر في كود الصفحة.

## 2) الدفع بالبطاقة

في `assets/app.js`:

```js
const PAY = {
  start:  "",   // باقة البداية — 400 ريال
  growth: "",   // باقة النمو — 600 ريال
  partner:""    // باقة الشريك — 1500 ريال
};
```

حط لينك الدفع لكل باقة، والزرار هيتغير تلقائيًا لـ **"ادفع الآن بالبطاقة"** وتحته زرار الواتساب زي ما هو. سيبها فاضية = يفضل زرار الواتساب بس.

### مهم بخصوص Stripe

**Stripe مبيقبلش حسابات مسجّلة في مصر ولا السعودية** — الإمارات بس في المنطقة. يعني تفتح Stripe مباشرة لو عندك كيان إماراتي أو أمريكي (Stripe Atlas).

### البدايل اللي تشتغل من مصر

| الخيار | ملاحظات |
|---|---|
| **Lemon Squeezy** (مرشّح) | مصر مدعومة رسميًا للبائعين. مملوكة لـStripe، بتقبل فيزا/ماستر/PayPal وبتحوّل على حسابك البنكي. اعمل منتج لكل باقة وخد لينك الشراء |
| **Paymob** | مصر — بطاقات محلية ومحافظ، Payment Links جاهزة |
| **PayPal** | للعملاء بره مصر، موجود أصلًا في طرق الدفع |

أي رابط دفع من أي خدمة هيشتغل — الكود مش مربوط بمزوّد معيّن.
