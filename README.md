# موقع كرم حراز — دليل التشغيل

موقع ثابت (Static) شغّال على GitHub Pages من غير أي سيرفر.

## الملفات

```
index.html      الرئيسية
projects.html   كل الأعمال
project.html    صفحة المشروع (project.html?id=maalem)
packages.html   الباقات والأسعار
contact.html    فورم "ابدأ مشروعك"
thanks.html     صفحة الشكر بعد الإرسال
404.html        صفحة الخطأ
assets/style.css
assets/app.js   ← كل الإعدادات والنصوص والمشاريع هنا
assets/fonts/   الخطوط مرفوعة مع الموقع (مفيش اعتماد على Google Fonts)
assets/projects/<id>/1..6.jpg
```

كل النصوص والبيانات في أول `assets/app.js` — قسم `CONFIG` و `PROJECTS` و `PACKS` و `STR`.

## 1) تفعيل الفورم (FormSubmit)

الفورم بيبعت على **karammh112@gmail.com** من غير حساب ولا لوحة تحكم.

1. ارفع الموقع على GitHub Pages.
2. افتح `contact.html` من الموقع المرفوع (مش من الجهاز) واملأ الفورم وابعت **أول رسالة**.
3. هيوصلك إيميل من FormSubmit فيه زرار **Activate Form** — اضغطه مرة واحدة وخلاص.
4. من بعدها كل الرسايل بتوصلك على طول.

**اختياري للحماية من السبام:** بعد التفعيل FormSubmit بيديك كود مشفّر بدل الإيميل.
افتح `assets/app.js` وغيّر السطرين دول:

```js
formEndpoint:"https://formsubmit.co/ajax/الكود-المشفّر",
formFallback:"https://formsubmit.co/الكود-المشفّر",
```

كده إيميلك مش هيبقى ظاهر في كود الصفحة.

**كمان اختياري:** حط رابط موقعك في `siteUrl` عشان لو الجافاسكريبت متوقف عند الزائر يتحوّل لصفحة الشكر:

```js
siteUrl:"https://username.github.io/repo",
```

## 2) الدفع بالبطاقة

الأزرار جاهزة. لما تحط الروابط في `CONFIG.pay` الزرار بيتغيّر تلقائيًا من "احجز الباقة" لـ **"ادفع الآن بالبطاقة"**:

```js
pay:{
  start:  "https://...",   // باقة البداية — 400 ريال
  growth: "https://...",   // باقة النمو — 600 ريال
  partner:"https://..."    // باقة الشريك — 1500 ريال
}
```

### مهم بخصوص Stripe

**Stripe مبيقبلش حسابات مسجّلة في مصر ولا في السعودية.** الدول المدعومة في المنطقة هي الإمارات بس.
يعني تفتح حساب Stripe مباشرة لو عندك كيان في الإمارات أو أمريكا (Stripe Atlas مثلًا).

### البدايل اللي فعلًا تشتغل من مصر

| الخيار | ينفع لمين | ملاحظات |
|---|---|---|
| **Lemon Squeezy** (مرشّح) | مصر مدعومة رسميًا للبائعين | مملوكة لـ Stripe، بتقبل فيزا/ماستر/PayPal، وبتحوّلك على حسابك البنكي في مصر. Merchant of Record — يعني هي اللي بتتعامل مع الضرايب. اعمل Product لكل باقة وخد الـ Checkout link |
| **Paymob** | مصر — بطاقات محلية + محافظ | Payment Links جاهزة، كويس للعملاء المصريين |
| **PayPal** | العملاء بره مصر | موجود أصلًا في طرق الدفع |

الخطوات مع Lemon Squeezy: حساب → Store → 3 منتجات (400 / 600 / 1500 ريال، أو بالدولار حسب اللي يناسبك) → انسخ لينك الشراء لكل واحد وحطه في `CONFIG.pay`.

أي رابط دفع من أي خدمة هيشتغل — الكود مش مربوط بمزوّد معيّن.

## 3) التعديل على المحتوى

* **مشروع جديد:** ضيف فولدر `assets/projects/<id>/` فيه `1.jpg` لحد `6.jpg`، وضيف بلوك جديد في `PROJECTS` داخل `app.js` (نفس شكل الموجود: `id`, `color`, `nAr/nEn`, `cAr/cEn`, `sAr/sEn`, `dAr/dEn`).
* **الباقات:** في `PACKS`. الأسعار والمميزات مكتوبة زي ما هي بالظبط.
* **أي نص في الموقع:** في `STR.ar` و `STR.en`.
* **بياناتك (واتساب، إيميل، بيهانس):** في `CONFIG` و `SOCIALS`.

## 4) الرفع على GitHub Pages

ارفع كل الملفات في جذر الريبو (مش جوه فولدر)، وبعدين
Settings → Pages → Source: `main` / `root`.

خلي بالك: فولدر `tracker/` الشخصي **مايترفعش** مع الموقع.
