## 3) الأمان — `vercel.json`

الملف ده بيضيف طبقة حماية على مستوى السيرفر. **لازم يترفع في روت الريبو** جنب `index.html`.
لو مترفعش، الموقع هيشتغل عادي بس من غير الحماية دي.

اللي بيعمله:

| الهيدر | بيمنع إيه |
|---|---|
| `frame-ancestors 'none'` + `X-Frame-Options` | إن حد يحطّ موقعك جوه إطار في موقع تاني ويحطّ فوق بيانات حسابك البنكي أرقام بتاعته (أخطر حاجة كانت مفتوحة) |
| `Content-Security-Policy` | إن حد يحقن سكربت خارجي في الصفحة أو يسرّب بيانات لسيرفر بره |
| `Strict-Transport-Security` | إن حد يفتح الموقع على HTTP ويتنصّت على الاتصال |
| `X-Content-Type-Options` | إن ملف صورة يتنفّذ كأنه كود |
| `Referrer-Policy` | تسريب لينك الصفحة اللي العميل جاي منها لكل موقع خارجي بتضغط عليه |
| `Permissions-Policy` | وصول الصفحة للكاميرا والمايك والموقع الجغرافي |
| `Cache-Control` | الصور بتتخزّن شهر عند الزائر (أسرع)، و`index.html` بيتشيك عليه كل مرة (عشان أي تعديل يبان فورًا) |

في كمان حماية جوه `index.html` نفسه:

- نسخة احتياطية من الـ CSP كـ `<meta>` — بتشتغل حتى لو `vercel.json` مترفعش
- كل اللينكات الخارجية بقت `rel="noopener noreferrer"` — الموقع اللي بيتفتح مش بيقدر يتحكم في تاب موقعك
- تاب واتساب بيتفصل عن الموقع قبل ما يتفتح
- حدود طول على كل خانة في الفورم (الاسم 80 حرف، الرسالة 2000) — يمنع الإرسال المتضخّم
- فخ روبوتات + فخ سرعة + سؤال تحقق قبل أي إرسال

## 5) تغيير الأسعار والباقات

  من غير أي حركة: 8 تصاميم في صفين على الكمبيوتر، وصفين × ٤ على الموبايل.
